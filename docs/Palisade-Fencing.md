# Palisade security fencing

Palisade Security Fence and Palisade Security Gate are galvanised silver steel blocks. Fence sections connect horizontally to fences, matching gates and sturdy block faces. Build corners and junctions like normal fencing.

Stack sections to any height within the world's build limits. Uprights line up vertically and the topmost fence/gate section shows the pointed pales. Every placed section is a separate item: breaking or sneak-wrenching one removes only that section.

## Gates

Stack gates to create a taller one-block-wide entrance. Newly placed sections align to the adjacent gate. A continuous vertical column with the same facing operates together. Right-click any section to open or close the column. Redstone power to any section holds it open; removing that power closes it. Gates next to each other horizontally operate independently. Removing a middle section creates independent columns.

Open gates fold their leaves to the sides and allow passage. Normal Create wrench use rotates the entire aligned column, subject to permissions on all affected sections. Sneak-wrench picks up only the selected section. Gate placement, fence connections and power checks do not intentionally load neighbouring chunks; only loaded power sources participate. Both blocks support waterlogging and pickaxe mining.

## Crafting

Four fence sections: two rows of iron ingot / iron nugget / iron ingot.

One gate section: shapelessly combine two Palisade Security Fence sections and one iron ingot.

The blocks also appear in the UK Railways creative tab. Install the same updated JAR on client and server. Native gameplay, shader and multiplayer acceptance remain pending until checked in-world.

## Fence panels above a gate

Place normal Palisade Security Fence sections above a gate column to form matching fixed infill. The infill automatically aligns its uprights and side posts with the gate below, continues through additional fence sections above, and removes the gate's pointed top beneath it. Opening the gate leaves the infill fixed overhead. Break the supporting gate or change its orientation and the fence layout updates accordingly. For an existing build after updating, open/close the gate to refresh its overhead infill; no replacement blocks are required.

Rails are inset from upright faces to prevent z-fighting. Open leaves also stand clear of the hinge posts. Three-high fence with two-high gates and overhead infill.
