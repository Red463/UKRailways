# Railway Ballast

Railway Ballast is a stable full block intended as a track bed. Place it under Create tracks or [UK Concrete Sleeper Track](UK-Concrete-Track.md), and beside the sleepers to build ballast shoulders. It does not fall like vanilla gravel. All six faces share the same angular grey crushed-stone material.

Find it in the UK Railways creative tab or craft four with this 2x2 recipe:

```text
Andesite     Gravel
Gravel       Cobblestone
```

A shovel is the preferred mining tool. Breaking returns the ballast block; Create sneak-wrench pickup is supported. Install the updated mod on server and clients. Native track-placement and shader appearance remain to be checked.
