# Buff tactile paving

Buff Tactile Paving and Buff Tactile Paving Slab reproduce platform-edge paving with staggered blister studs and a fine square grid. The original texture tiles continuously; the blisters are shaded into the texture, so walking collision stays flat.

Full blocks and slabs appear in the UK Railways creative tab. Slabs use standard Minecraft bottom, top and double placement. Single slabs support waterlogging; double slabs drop two slab items. Mine either with a pickaxe or sneak-right-click with a Create wrench to pick up the placed block. A double slab returns two slab items through wrench pickup too.

Craft four paving blocks from a two-by-two square of smooth sandstone. Craft six slabs from three paving blocks in a horizontal row. These add two recipes, bringing the mod total to 40.

Install the updated JAR on both client and server. Native gameplay, shaders and multiplayer acceptance remain pending until checked in-world.
