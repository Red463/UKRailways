# Railway engineer workwear

Four cosmetic pieces appear in the Create: UK Railways creative tab:

- Railway Engineer Hard Hat: white raised crown and brim; head slot.
- Railway Engineer Hi-Vis Jacket: orange with silver reflective bands; chest slot.
- Railway Engineer Hi-Vis Trousers: orange with two reflective leg bands; legs slot.
- Railway Engineer Work Boots: dark ankle boots and soles; feet slot.

Right-click a held piece or place it in its normal armour slot. Pieces can be worn individually or together, including with other equipment. Clothing follows normal player poses, including walking/crouching and slim-arm skins. The front/rear/slim/walking preview uses the actual model geometry and UV textures; it is an offline render.

This is **cosmetic clothing with no protection**. It adds no armour, toughness, knockback resistance or other attribute modifiers. It has no durability to lose and cannot receive normal armour enchantments. It occupies the usual armour slots, so equipping it replaces any protective armour in those slots.

## Crafting

Each recipe produces one piece. Patterns are shown top to bottom; `.` means an empty slot.

| Piece | Pattern | Ingredients |
|---|---|---|
| Hard hat | `NNN / NDN / .L.` | N = Iron Nugget; D = White Dye; L = Leather |
| Hi-vis jacket | `O.O / ROR / ORO` | O = Orange Wool; R = Light Gray Wool |
| Hi-vis trousers | `OOO / R.R / O.O` | O = Orange Wool; R = Light Gray Wool |
| Work boots | `L.L / LBL` | L = Leather; B = Black Dye |

Recipes unlock in the recipe book when you obtain their main material. See [the complete crafting guide](Crafting.md).
