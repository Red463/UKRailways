# Railway Tablet

Craft a Railway Tablet and right-click while holding it in either hand to open the live, read-only railway network map. It works anywhere without linking to a railway computer, including when aiming at a block. Operator permission is not required.

## Crafting

```text
III
GCG
IRI
```

I: iron ingot; G: green stained glass; C: compass; R: redstone dust.
Each recipe makes one tablet. Tablets do not stack.

## Using the map

Drag to pan, scroll or use +/- to zoom, and use Fit network or Dimension to change the view. Select trains, stations and signals for details. The existing train picker and carriage symbols are available.

Each tablet remembers its own dimension, map centre and zoom when you close the screen normally. Keep the same tablet held while viewing: changing the selected slot, swapping the held tablet or changing dimension closes the map. Updates stop when access ends; interrupted sessions expire on the server. Saving a view does not grant train controls or change railway blocks.

The map uses the same server snapshots as the railway computer. Stale or partial data remains marked; the tablet does not force-load chunks. The browser viewer and its invitation authentication are unchanged.
